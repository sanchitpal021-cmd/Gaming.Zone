# 🎮 Arcade Game Zone

**One website. Multiple games. Endless fun!**

Welcome to **Arcade Game Zone**, a mini gaming platform that brings multiple classic games together in one place. This project is designed to make gaming simple, interactive, and enjoyable through a clean interface, engaging animations, and an arcade-inspired design.

## ✨ About the Project

Arcade Game Zone is a personal web development project where users can explore and play different mini-games without switching between multiple websites.

The goal is to combine entertainment with creativity while improving my skills in HTML, CSS, and JavaScript.

## 🕹️ Available Games

- **Tic-Tac-Toe:** Challenge another player in this classic X and O strategy game.
- **Snake Rush:** Control the snake, collect food, and try to achieve a high score.
- **Rock Paper Scissors:** Play against the computer and test your luck and strategy.

## 🚀 Features

- Multiple games in one platform.
- Interactive gameplay and controls.
- Arcade-inspired user interface.
- Dark and light theme option.
- Score tracking.
- CSS animations and visual effects.
- Simple and easy-to-use navigation.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling, layouts and animations |
| JavaScript | Game logic and interactivity |

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Find the `index.html` file.
4. Open it in your web browser.
5. Choose a game and start playing!
